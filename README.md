# Recall – Client memory for banks

Hackathon prototype for the challenge *Customer Know-How Repo / Self-Learning CRM*.

Recall turns scattered client information (opening documents, KYC evidence, emails, meeting notes, CRM records) into one account view that a relationship manager can trust:

- **Client overview** with today's focus, risks, people and a timeline
- **KYC profile** covering identity, tax (CRS/FATCA), Form A, source of wealth and funds, screening and suitability
- **Documents** checklist for account opening and KYC evidence, with request actions
- **Conflicts & gaps** where sources disagree, are outdated or incomplete
- **Meeting prep** with questions and next steps
- **Learning loop**: new emails become proposed updates, reviewed by the RM and, for KYC changes, by compliance (four-eyes)
- **Trust & controls**: source traceability, labels for facts vs. inferences, audit trail, clear limits

Every statement links to the exact passage in its source.

> All data is fictional and hard-coded. No backend, no real client data.

## Run locally

Open `index.html` in any browser. It is a single self-contained file (React, Tailwind CSS, Framer Motion and Lucide are bundled inline).
